# Apps

Small tools that run on your own computer.

| Folder | What it does |
|---|---|
| [`markdown-to-latex/`](markdown-to-latex/) | Upload a Markdown (`.md`) file and get a well-organised LaTeX document and a printable PDF. Open `index.html` to try it; add the optional helper (`serve.py`) to build real PDFs. See the [README](markdown-to-latex/README.md). |
| [`drone-cad/`](drone-cad/) | *Planning only.* A drone-mapping and CAD desk for you and your staff: view DJI Terra or OpenDroneMap outputs (orthomosaic, DSM/DTM, contours), draw and label plot boundaries with CAD snapping, measure, and export DXF/SHP. See the [plan](drone-cad/PLAN.md). |
