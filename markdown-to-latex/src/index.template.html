      Getting a PDF

      A PDF is made from the LaTeX file by a LaTeX engine. You have three ways to get one:

      A · Create it on this computer (best)

      1. Install a LaTeX distribution: MiKTeX (Windows), MacTeX (macOS) or TeX Live (Linux). Tectonic is a small alternative.

      2. Start the helper in this folder: python3 serve.py (Windows: py serve.py). It opens this page with Create PDF switched on.

      B · Use Overleaf (nothing to install)

      Click Download project (.zip), then on overleaf.com choose New Project → Upload Project and select the zip. In the project menu set the compiler to XeLaTeX. Overleaf is a third-party website: your document is uploaded there.

      C · Print the quick preview

      The Quick preview tab can be printed or saved as a PDF by your browser. It is not typeset by LaTeX, so fonts and layout differ.
