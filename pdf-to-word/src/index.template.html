    How the recovery works

    A PDF is a list of text fragments with coordinates. It has no paragraphs, no columns and no tables. Black Box puts them back by measuring.

    01Read

    Every fragment is read with its position, font, size and colour. Lines, rules and shaded boxes are read the same way. This is the wreckage.

    02Rebuild

    Fragments on one baseline become lines. Gaps that line up down the page become columns or table cells. Size and weight decide headings. Bullets and numbers become lists.

    03Write

    The result is real Word structure: heading styles, list numbering, tables with merged cells, page number fields and a proper header and footer. A ledger checks that every letter made it.

    What it won't do

    The honest list, so there are no surprises in Word.

    Scans

    A scanned page is a photo of text. Reading it means OCR, which is machine learning, and this tool has taken a stand. Scanned pages go into the Word file as pictures.

    Fonts

    Word swaps in a similar font when yours is missing. Sizes, weights and colours still come across.

    Wrapped pictures

    Text that wraps around a picture is flattened. The picture comes first, then the text.

    Sideways text

    Rotated text is set aside and counted in the manifest, so you know it was left out.

    Charts

    Charts and diagrams drawn from vector shapes are kept as pictures, labels included. They look right but are not editable.

    Page breaks

    Word sets lines with its own font metrics, so pages may break in different places. Turn on Keep every page break to follow the original.
